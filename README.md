# Floating Resume Template

An anime-inspired static 3D resume with floating islands, a reversible flight
journey and day/night themes. The default profile is entirely fictional.

## Get started

Use Node.js 22.13+ and pnpm 11.19.0:

```sh
pnpm install --frozen-lockfile
pnpm validate:resume
pnpm typecheck
pnpm test
pnpm preview
```

Edit content/resume.json or use the included resume-to-profile skill.
See [profile setup](docs/profile-format.md). Static output is dist/client.
